# 🏠 NCR Real Estate Market Analysis

An interactive Business Analytics project for analyzing the **Gurugram (NCR) real estate market** using Python, Pandas, Plotly, and Streamlit.

The project transforms raw real estate data into meaningful business insights through **data cleaning, exploratory data analysis, and an interactive dashboard**.

---

## 📊 Project Overview

The objective of this project is to analyze real estate properties in Gurugram and identify patterns related to:

- Property prices
- Price per square foot
- Property types
- BHK configuration
- Locality-wise listings
- Property status
- RERA approval
- Area and pricing relationships

The final output is an interactive dashboard that allows users to explore the market using filters and visualizations.

---

## 🚀 Key Features

- 📌 Interactive Streamlit dashboard
- 💰 Property price analysis
- 📍 Locality-wise property analysis
- 🏢 Property type distribution
- 🛏️ BHK-wise average price analysis
- 📐 Area vs Price analysis
- 💵 Rate per square foot analysis
- 🏗️ RERA approval analysis
- 📊 Property status analysis
- 🔎 Interactive filters
- 📈 Interactive Plotly visualizations
